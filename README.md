# 🌐 NetPractice

## 📝 Description
The **NetPractice** project is a general practical exercise designed to introduce the basics of **computer networking**. The challenge is to configure network setups across 10 various levels using interface **IP addresses**, **subnet masks** and **routing tables**. The goal is to establish full two-way communication between **hosts**, **routers**, **switches** and the **Internet** without causing IP conflicts or routing loops.

### 💡 what did i learn from the project
Working with network setups was a great learning experience. I learned how to divide a **network** into smaller parts using **subnet masks** and how to calculate the correct range of **IP addresses** for each group. Also, I learned how **routers** forward packets between different networks to help them communicate correctly, as well as the difference between **switches** and **routers**.

## 🔗 Resources
1.  ### 🧠 The networking concepts studied :
-  **TCP/IP addressing and subnet masks** : Divided IPv4 addresses into Network and Host address using CIDR and subnet masks to assign valid IP ranges and calculate usable IP limits per subnet. 
- **default gateways** : The router acts as the default gateway. By using its IP interface as the Next Hop in routing tables, so devices can communicate across different networks.
- **routers and switches** : A switch connects multiple devices (hosts) within the same local network (LAN), while a router connects different networks together using non-overlapping IP interfaces on each connection.
- **OSI layers** : Understood how data moves across network layers, focusing on Layer 2 (Data Link layer for switches in the same network) and Layer 3 (Network layer for IP routing between different networks) and Layer 4 (Transport layer TCP as a communication standard protocol).
